# Public evaluation artifacts

`phase3-summary.json` contains historical aggregate measurements from September 28–29, 2026. `synthetic-demo.json` contains six explicitly authored fictional reports in English, Chinese and Spanish, reused from the existing synthetic diagnostic function. It exercises the evaluation path but cannot reproduce the historical benchmark.

Publisher excerpts, real-source quotes, source-level operational snapshots and raw LLM outputs are intentionally not distributed. The complete research artifacts remain locally archived. No restricted data from unpublished local commits is part of this release branch. Existing public history is preserved.

See [methodology and instructions](../docs/evaluation.md). Model reviews are fallible, and diagnostic results are not population accuracy.
