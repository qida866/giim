# Phase 3: bounded story recall and consolidation

The frozen Phase 2 evaluation loses 42 positive pairs at semantic candidate gates and nine through complete-link/greedy grouping. Its four false pairs share actors but have different primary actions. Publication-time boundaries did not explain those misses.

Keep bge-m3 and the existing time-window HDBSCAN thresholds. Supplement discovery with nearest semantic candidate pairs, optionally supported by uncommon headline tokens. The weaker retrieval floor is not a merge threshold. Limit a candidate union to seven publication days and 24 reports. Require a full-member incident/developing-story review, exact identifying quotations, and a second headline-only primary-action/participant audit. Separate-topic or uncertain decisions remain separate. For custody/proceedings, affected people must match; for military support, both grantor/refuser and recipient must match. This prevents a common political party or crisis from standing in for occurrence identity, at the cost of additional false negatives from inconsistent name extraction.

Lowering all clustering thresholds would directly trade precision for recall; replacing the embedding or clustering architecture would invalidate the baseline. The chosen staged approach preserves it and spends bounded LLM work only on retrieved candidates. It costs additional review calls and can under-merge sparse or differently named reports. The reviewer remains fallible, so retain all trial results and inspect ambiguous cases outside the scored metrics.

After identity passes, select up to eight current publisher-diverse evidence reports, generate the existing structured brief, then retain Phase 2 claim-support review. Keep all historical members but distinguish current support IDs. A material change anywhere in membership invalidates story review; whitespace-only changes do not. Pending revalidation withdraws the previous AI claims and publishes an attributed current excerpt. A failed review cools down for two hours only while the complete evidence hash and matching version remain unchanged; material changes bypass that cooldown.

Consolidation uses the existing pipeline advisory lock and one database transaction. Choose the earliest existing identity, preserve both source lineages and revision snapshots, retain superseded records and links, and reject an unreviewed overlapping active card. Lock and recheck source evidence before committing. No schema migration is required.

Normalize legacy publisher names at read time using the registry. Expand the existing official USGS discovery feed from one day to seven days; official event identifiers override generic headline similarity. Official observations are not extra independent publishers. URL changes invalidate conditional HTTP validators.

Validation: frozen 90-report pair matrix, expanded explicitly labeled relationships, source-revision and atomic-history tests, live before/after card audit at a fixed observation window, dated independent reference selection, and bounded repeat-run cost checks. The expanded set became diagnostic after failure-driven iteration; it is no longer an untouched holdout. There is no human-adjudicated population accuracy claim.
